# 🍽️ FoodLovers — Discover & Share Authentic Food Reviews

**Live Site URL:** [https://foodlovers-client.vercel.app](https://foodlovers-client.vercel.app)

FoodLovers is a modern web application where users can explore, review, and share their favorite foods and restaurants across Bangladesh. Built with React and Firebase, it offers a smooth, fast, and interactive user experience.

---

## 🚀 Features

- **🔐 Secure Authentication** — Users can sign up and log in seamlessly using Firebase authentication.
- **⭐ Post & Manage Reviews** — Authenticated users can write, edit, and delete their food reviews with photos and ratings.
- **🍛 Explore Local Dishes** — Discover authentic Bangladeshi foods from various cities with detailed user feedback.
- **🏆 Top Reviewers Leaderboard** — See which users contribute the most reviews, ranked dynamically using MongoDB aggregation.
- **⚡ Responsive UI & Animations** — Built with modern React components, Swiper sliders, and Lottie animations for smooth visuals.
- **📱 Fully Responsive Design** — Optimized for mobile, tablet, and desktop viewing.

---

## 🧩 Tech Stack

- **Frontend:** React 19, React Query, React Hook Form
- **Backend:** Node.js, Express.js, MongoDB
- **Authentication:** Firebase
- **Styling & Effects:** Tailwind CSS, Swiper.js, Lottie Animations, SweetAlert2
- **State & Data:** TanStack React Query for caching and API state management
